How to Play

Match colorful gems to restore the rainbow before the storm takes over.

Drag or tap a gem to swap it with an adjacent gem.
Match 3 or more gems of the same color to clear them.
Restore colors in rainbow order: Red → Orange → Yellow → Green → Blue → Indigo → Violet.
Complete the full color sequence to trigger a powerful Rainbow Rush.
Match 4 gems to create a Prism Gem.
Match 5 gems to create a powerful Unicorn Blast.
Gray Storm Clouds will appear as you play. Clear them by matching gems next to them or by using a tool.
Restore 3 complete rainbows before you run out of moves to win.
Magic Tools
Rainbow Brush — Paints one gem into the current target rainbow color.
Cloud Breaker — Removes one Storm Cloud instantly.
Prism Burst — Clears a 3×3 area around the selected tile.
Goal

Restore 3 rainbows before your moves run out.

Chain colors in the correct order, create special gems, use your tools wisely, and unleash as many Rainbow Rushes as possible.
